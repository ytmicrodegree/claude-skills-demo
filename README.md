# Claude Skills Demo

Two reusable Claude skills from the video, plus the demo prompts.

## Skills

| Skill | What it does |
| --- | --- |
| [dev-review-debug](dev-review-debug/SKILL.md) | Code review, debugging, PR descriptions, commit messages |
| [work-clarity-assistant](work-clarity-assistant/SKILL.md) | Meeting notes, emails, thread summaries, day planning, meeting prep |

## Demo prompts

Open the prompts page and use the copy buttons:
https://ytmicrodegree.github.io/claude-skills-demo/

## How to use a skill

1. Open the skill's SKILL.md file and copy its content.
2. Save it as SKILL.md inside a folder named after the skill.
3. Upload it through your Skills settings in Claude.
4. Call it with /skill-name, or just describe your task and Claude picks it.

You can also paste the content at the start of a chat to use it as a plain prompt.
